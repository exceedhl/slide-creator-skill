激进透明哲学与技能导向

  • 透明度作为信任货币 公开薪酬计算公式与职级定义，彻底消除“谈判税”。预先展示极具竞争力的薪酬范围，充当高效的自动筛选器。
  • 支付技能而非头衔 去头衔化（De-titling），强调角色（Role）而非地位（Status）。极宽的薪酬带宽避免了优秀的个人贡献者（IC）被迫转岗管理。
  • 高绩效锚点 坚信顶尖工程师产出是普通人的10倍。薪酬基准直接对标全球最高水平——旧金山市场的第90分位，用溢价吸引全球顶尖人才。

薪酬算法的解构：精密计算的四个维度

Base Salary = Benchmark × Level Modifier × Step Modifier × Location Factor

1. Benchmark (市场基准)

所有薪酬计算的起点。明确锚定美国旧金山 (SF) 的市场费率。工程类角色对标第90分位，非工程类角色对标中位数+20%。依托 Pave 的实时数据，拒绝传统调查问卷的滞后性。

2. Level Modifier (级别因子)

采用极宽泛的职级定义 (Junior / Intermediate / Senior / Staff)，适应“小团队”灵活运作。新员工默认处于Established Step，预留薪资增长空间，打破“不晋升不加薪”的传统层级桎梏。

3. Step Modifier (步长因子)

数值范围：0.95 - 1.04。作为同一级别内区分成熟度的微调杠杆，允许薪资上下浮动 5%-10%。管理者可借此给予员工即时的肯定与奖励，而无需启动沉重的晋升评审流程。

4. Location Factor (位置因子与全球保底)

双保底政策：美国境内下限 0.8，全球其他地区下限 0.6。
极具颠覆性的设定，不仅能在发展中国家创造压倒性的人才购买力（降维打击），同时也为公司节省大量现金流（成本套利）。

基于产品矩阵的销售佣金模型

不同于传统 SaaS 简单基于合同金额 (TCV) 提成，PostHog 高度强调 年度经常性收入 (ARR) 和 产品交叉销售 (Cross-sell)。
其核心创新在于“交叉销售乘数”，迫使销售行为从推销单一功能转向售卖整个平台价值。

股权即所有权：打破“金手铐”与终极激励

颠覆性的 10 年期权行权窗口

大多数公司离职后只有90天行权期，这是变相的资产剥夺。PostHog 赋予离职员工长达 10年 的行权窗口，彻底消除财务压力，让员工保留创造的价值份额，转化为终身拥护者。

“无审批”的远程作战弹药

每位员工每月有 $5,000 的限额用于购买SaaS、书籍或联合办公。完全“先花钱，后审计”，消除摩擦力。此外每季度提供 $1,500 用于员工自发见面聚餐，对抗远程孤岛。

做你离职后的第一位投资人

工作满2年离职创业，PostHog 承诺成为其第一位投资者。通过这种合伙人式的纽带，吸引最具“创始人精神”的顶尖人才全情投入。

组织文化与精益方法论：孕育创新的土壤

小团队自治

公司拆分为一个个独立的“小团队”（Small Teams），拥有极高自主权、路线图和定价权。

管理与薪酬解耦：经理无权决定下属薪酬，薪酬完全由透明公式决定。经理不再是“监工”，而是“教练”，彻底消除了办公室政治。

精益软件开发

消除一切浪费（等待审批、不必要的会议）。

速度优于完美：容忍一定程度的混乱以换取快速迭代。

Andon Cord 机制：任何人都有权因 CI/CD 失败而“拉下安灯绳”停止生产线，鼓励对质量的即时反馈。

全栈价值流

通过 Product Engineer 角色，消除从 PM -> 设计师 -> 前端 -> 后端的漫长交接链条。

这种极其扁平的高效价值流（Value Stream Mapping），必须匹配市场 第 90 分位 的顶级薪酬才能维持。
