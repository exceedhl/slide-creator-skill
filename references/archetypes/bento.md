# Archetype: bento

**必须使用大小不一的 Bento Grid 卡片混排**。这是最高设计方差的布局。

```
✅ 必须遵循的 Bento 原则:
   - 大卡片 (14-16col × 10-12row) 与小卡片 (8-10col × 5-6row) 混排
   - 允许不同行的卡片高度不一致
   - 至少一个"英雄卡片"占据 >50% 的视觉面积
   - 允许刻意留出 2-4col 的空列作为呼吸空间
   - 组件之间允许 1-2 row/col 的刻意空白，模拟自然的间距感
    
❌ bento 中禁止:
   - 所有卡片大小一致
   - 严格的行列对齐（可以有 1-2 row 的错位）
```
